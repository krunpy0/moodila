# Architectural Decision Records (ADR)

В этой директории зафиксированы ключевые архитектурные решения проекта **Moodila**. 

Каждая запись отражает проблему, выбранное решение, причины выбора, накладываемые ограничения и отвергнутые альтернативы. Записи сформированы на основе анализа существующего продакшен-кода, схемы базы данных, истории git-коммитов и результатов нагрузочного тестирования.

> [!IMPORTANT]
> **Правило для AI-агентов и разработчиков:**
> Перед тем как предлагать рефакторинг или изменение базовых механизмов системы, обязательно изучите соответствующие ADR. Не отменяйте и не переделывайте принятые решения без явного указания пользователя и глубокого понимания причин, по которым эти решения были реализованы.
